# Adjektive mit Präpositionen — Quiz

An interactive German quiz focused on **Adjektive mit Präpositionen** for learners around the **B2–C1** level.

The project provides:
- multiple-choice questions
- instant feedback
- progress tracking
- mistake review mode
- keyboard shortcuts
- elegant responsive UI

## Features

- 🎯 Randomized quiz system
- 📚 Large dataset of adjective–preposition combinations
- ✅ Immediate correction and explanations
- 📊 Final score statistics
- 📝 Review section for wrong answers
- ⌨️ Keyboard navigation support
- 🌙 Modern dark interface

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or external dependencies are required.

Simply open the HTML file in your browser:

open adjektive_quiz.html
